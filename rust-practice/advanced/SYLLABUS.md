# Rust Advanced Course

這是一門以 Rust 學習程式設計、系統資源與可靠介面設計的進階課程。重點是從規格推理、解釋設計取捨，再以程式與測試提供證據；不是只背語法或修到編譯成功。

## 前置知識與操作環境

先完成 [Rust Beginner Course](../beginner/README.md)，能獨立使用變數、判斷、迴圈、函式、基本所有權、Vec、Option、Result 與測試。熟悉終端機、Cargo 與編輯器；不要求 C++ 背景。需要支援 Rust 2024 edition 的工具鏈（Rust １．８５ 以上），建議使用目前 stable。安裝見 [跨平台說明](../beginner/README.md)。所有命令除另註外，先進入 advanced 資料夾再執行。

## 每章學習方法

先讀理論與契約，手動追蹤正常及失敗案例，再閱讀起始程式的測試。自己完成 `examples/labNN.rs`，新增邊界測試；卡住才讀提示，完成後比較參考解法。所有起始程式含 `todo!()`，測試失敗是待完成的狀態。

每章外部驗收至少十個獨立具名檢查，清單見 [TEST_CASES.md](TEST_CASES.md)。第四章固定事件序列為十項契約性質檢查，不宣稱十種不同輸入。

每章用 `cargo run -p rust-advanced-course -- run N` 自動驗收函式契約；第十二章另測多組標準輸入、輸出及退出碼。`manual N [args...]` 保留手動互動，`test N` 執行原檔測試。驗收不修改作答，有逾時限制但不是安全沙盒；它提供有限案例的證據，無法自動判定推理、複雜度與設計品質。

每章繳交程式、驗證紀錄與一頁設計說明，回答：規格是什麼？不變量是什麼？哪些錯誤由型別防止、哪些須執行期處理？時間與額外空間成本是多少？測試沒有證明什麼？

## 評量規準

| 面向 | 比例 | 可觀察的證據 |
|---|---|---|
| 理論與推理 | ２５％ | 正確描述執行模型、契約、不變量及終止理由 |
| 設計與取捨 | ２５％ | 型別與介面符合規格，能比較替代方案及成本 |
| 實作正確性 | ３０％ | 一般與邊界案例符合契約，錯誤行為可預期 |
| 測試與限制 | ２０％ | 自訂有效測試、可重現操作，明確交代未涵蓋範圍 |

可將平時章節占總成績六成、期末整合專案占四成。參考測試不是完整規格的替代品；通過有限測試不等於一般性證明。小組專案仍需個別口頭解釋所有權與介面選擇。

## 課程範圍與限制

涵蓋契約、數值表示、搜尋、所有權、借用、生命週期、資料建模、泛型、迭代器、錯誤與基本執行緒。這不是完整的 async、unsafe、作業系統、編譯器或形式驗證課程，也不以完成本課程保證生產系統設計能力。科學數值實例會說明浮點限制，但不是完整數值分析課。教材尚未正式試教；教師應依學生先備知識調整節奏。

## 教材與維護

各章 `lessons/NN.md` 與程式檔是維護來源。修改章節後執行 `python3 scripts/build.py` 重建 COURSE.md；此動作不會覆寫學生程式。`cargo test --doc` 檢查教材中的 Rust 與預期編譯失敗範例。參考來源列於每章末。
