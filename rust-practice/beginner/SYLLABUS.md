# Rust Beginner Course：課綱

以Rust教授程式設計，對象包含零程式經驗學生。Beginner指先備門檻；課程要求描述問題、設計資料與流程、驗證結果並說明限制。

## 暫借與回收

第二～四單元使用已提供的單值輸入工具；第五單元回收呼叫概念，第六單元拆解stdin。第六單元暫用&mut模板，第七單元完成借用模型。第五單元先採明確標記的測試框架，第十一單元深化測試，第十二單元完整教跨檔案模組。

第十單元先完整match，再比較?；map_err與閉包是理解後的選讀，不是作答門檻。單元示範與原作業使用不同問題，提示和答案分開。

## 結業能力

- 在課程外建立Cargo專案，解釋編譯、執行、測試與參數。
- 從需求辨認資料、規則與邊界，拆成小函式。
- 使用選擇、重複與多筆輸入，追蹤狀態並解釋終止。
- 讀寫集合與文字，用所有權及借用說明介面。
- 選擇struct／enum／Option／Result，處理無值與可預期錯誤。
- 使用基本搜尋、排序與分組，說明主要成本。
- 讀寫文字檔、整理模組、處理錯誤輸出與退出碼。
- 自行設計能抓錯的測試，查文件並交代限制。

## 範圍與後續

基本資源模型屬本課；詳細生命週期、trait／泛型設計、不變量證明、進階成本與並行到 [Advanced](../advanced/SYLLABUS.md)深化。遞迴、完整資料結構、GUI、網路、async與unsafe不列為本課必要條件；若學校原課綱要求，須另外規劃，不宣稱已涵蓋。

不同C++／Python課程範圍不同，以共同能力對應，不照搬每個語言特色。課程尚未試教，不以教材篇幅推定學生已學會，也不保證固定教學時數。
