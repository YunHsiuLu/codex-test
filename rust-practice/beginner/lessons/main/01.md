# 第 1 步：讓程式說話

## 核心觀念

fn main() 是程式入口；println! 是巨集，會在文字後換行。字串放在雙引號內，敘述通常用分號結束。

## 起始程式

```rust
fn main() {
    println!("Hello, Rust!");
}
```

## 動手練習

讓程式依序輸出「Hello, Rust!」及「我正在學 Rust」。先預測目前程式會印出幾行。

自動驗收：`cargo run -- run 1`。手動執行：`cargo run -- manual 1`。

## 提示

新增一個 println!；中文也可以放進字串。

## 預期結果

```text
Hello, Rust!
我正在學 Rust
```

驗收：兩行文字與標點完全相同。

## 參考答案

```rust
fn main() {
    println!("Hello, Rust!");
    println!("我正在學 Rust");
}
```
