# 第 5 步：函式與檢查

## 本課分成兩節

5-1 是原本的函式與速度實作，直接使用 assert!；5-2 集中補充 assert!、assert_eq!、assert_ne!、panic! 與 debug_assert!。主線題目不再插入一長段補課。

在 beginner 資料夾執行：

```sh
cargo run -- lesson 5-1
cargo run -- lesson 5-2
```

5-1 繼續編輯原本 examples/step05.rs，以 cargo run -- run 5-1 驗收；原本 run 5 保留相同十項驗收。5-2 是補充教材，不需要提交新程式、不會列出假造的通過數。

Markdown 閱讀入口：[5-1 實作](05-1.md)、[5-2 補充教材](05-2.md)。
