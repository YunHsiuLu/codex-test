# 作業 5-3：把問題拆成可重用函式

## 先備與目標

先完成單元 5 的必讀教材，並已完成單元 4 的必要內容。把本單元的模型運用到新的問題，不必模仿教材的變數名稱。

## 規格與資料範圍

完成 `rectangle_area(width:i64,height:i64)->i64` 與 `paint_cost(width:i64,height:i64,price:i64)->i64`。所有參數為 0～1000000 的整數，前者求面積，後者求面積×單價。paint_cost 應重用面積函式；自動驗收查兩者結果，重用與拆解理由另外檢查。

## 作答與操作

編輯 `examples/unit05_03.rs`；需要保留題目明訂的函式名稱、參數與回傳型別。實作方式可自行選擇，沒有要求的額外限制不要自行加入。

```sh
cargo run -- lesson 5-3
cargo run -- manual 5-3
cargo run -- run 5-3
```

本題自動驗收範圍：函式契約：外部測試直接呼叫指定函式。main 只供示範，不要求你額外完成畫面輸出；自行測試 main 可用 manual。

參考答案只由 `cargo run -- answer 5-3` 顯示。先自己設計，再比較；提示是 `cargo run -- hint 5-3`。

## 呼叫範例與預期回傳

### 範例1

呼叫：`rectangle_area(2, 3)`

預期回傳／狀態：6。

### 範例2

呼叫：`paint_cost(2, 3, 4)`

預期回傳／狀態：24。

上述是函式結果，不是要求印出的文字；請自行推演其他符合規格的情況。
