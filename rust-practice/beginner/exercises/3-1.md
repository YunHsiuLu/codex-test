# 作業 3-1：成績級距

## 先備與目標

先完成單元 3 的必讀教材，並已完成單元 2 的必要內容。把本單元的模型運用到新的問題，不必模仿教材的變數名稱。

第二～四單元的 `support::read_i64`／`read_f64` 是本課提供、已完成的輸入工具，不是 Rust 內建。每次呼叫讀一行；本題保證輸入符合下列契約。暫時保留 `use` 與讀取呼叫，第六單元會拆解標準輸入。

## 規格與資料範圍

輸入 0～100 的整數分數；90 以上 A，80～89 B，70～79 C，60～69 D，其餘 F。只輸出一個英文字母。

## 作答與操作

編輯 `examples/unit03_01.rs`；需要保留題目明訂的函式名稱、參數與回傳型別。實作方式可自行選擇，沒有要求的額外限制不要自行加入。

```sh
cargo run -- lesson 3-1
cargo run -- manual 3-1
cargo run -- run 3-1
```

本題自動驗收範圍：完整程式：自動餵入 stdin，檢查 stdout、stderr 與退出碼。

參考答案只由 `cargo run -- answer 3-1` 顯示。先自己設計，再比較；提示是 `cargo run -- hint 3-1`。

## 呼叫範例與預期輸出

### 範例1

stdin（每行資料後按Enter）：

```text
85
```

stdout：

```text
B
```

### 範例2

stdin（每行資料後按Enter）：

```text
45
```

stdout：

```text
F
```
