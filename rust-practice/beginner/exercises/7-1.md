# 作業 7-1：只讀借用與文字單位

## 先備與目標

先完成單元 7 的必讀教材，並已完成單元 6 的必要內容。把本單元的模型運用到新的問題，不必模仿教材的變數名稱。

## 規格與資料範圍

完成 `scalar_count(text:&str)->usize`，回傳 Unicode scalar 數量，並不等同人眼字數。不得改成只接受 String。呼叫者仍可持有與使用原 String。

## 作答與操作

編輯 `examples/unit07_01.rs`；需要保留題目明訂的函式名稱、參數與回傳型別。實作方式可自行選擇，沒有要求的額外限制不要自行加入。

```sh
cargo run -- lesson 7-1
cargo run -- manual 7-1
cargo run -- run 7-1
```

## 呼叫範例與預期回傳

### 範例1

呼叫：`scalar_count("Rust")`

預期回傳／狀態：4。

### 範例2

呼叫：`scalar_count("物理")`

預期回傳／狀態：2。

上述是函式結果，不是要求印出的文字；請自行推演其他符合規格的情況。
