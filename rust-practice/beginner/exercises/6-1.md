# 作業 6-1：從標準輸入取得文字

## 先備與目標

先完成單元 6 的必讀教材，並已完成單元 5 的必要內容。把本單元的模型運用到新的問題，不必模仿教材的變數名稱。

## 規格與資料範圍

使用 std::io 自行讀一行。去除兩端空白後，非空輸出 `Hello, NAME!`；空白或立即 EOF 輸出 `empty`。只處理第一行，不輸出提示。不使用前段 support 工具。

## 呼叫範例與預期輸出

### 範例1

stdin（每行資料後按Enter）：

```text
Amy
```

stdout：

```text
Hello, Amy!
```

### 範例2

stdin（每行資料後按Enter）：

```text
  Rust learner
```

stdout：

```text
Hello, Rust learner!
```
