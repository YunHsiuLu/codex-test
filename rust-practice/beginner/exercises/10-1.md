# 作業 10-1：可恢復的解析錯誤

## 先備與目標

先完成單元 10 的必讀教材，並已完成單元 9 的必要內容。把本單元的模型運用到新的問題，不必模仿教材的變數名稱。

## 規格與資料範圍

完成 `parse_positive(text:&str)->Result<f64,String>`。trim後解析，僅接受有限且>0的值。空字串、非數字、零、負數、NaN與正負無限大均Err。錯誤文字自由，但不得用panic代替Err。

## 作答與操作

編輯 `examples/unit10_01.rs`；需要保留題目明訂的函式名稱、參數與回傳型別。實作方式可自行選擇，沒有要求的額外限制不要自行加入。

```sh
cargo run -- lesson 10-1
cargo run -- manual 10-1
cargo run -- run 10-1
```

本題自動驗收範圍：函式契約：外部測試直接呼叫指定函式。main 只供示範，不要求你額外完成畫面輸出；自行測試 main 可用 manual。

參考答案只由 `cargo run -- answer 10-1` 顯示。先自己設計，再比較；提示是 `cargo run -- hint 10-1`。

## 呼叫範例與預期回傳

### 範例1

呼叫：`parse_positive(" 2.5 ")`

預期回傳／狀態：Ok(2.5)。

### 範例2

呼叫：`parse_positive("abc")`

預期回傳／狀態：Err(String)，錯誤訊息自由。

上述是函式結果，不是要求印出的文字；請自行推演其他符合規格的情況。
