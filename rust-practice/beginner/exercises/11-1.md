# 作業 11-1：測試能抓出邊界錯誤

## 先備與目標

先完成單元 11 的必讀教材，並已完成單元 10 的必要內容。把本單元的模型運用到新的問題，不必模仿教材的變數名稱。

## 規格與資料範圍

已提供正確 ticket(age:u32)->u32：0～5歲0元、6～17歲50元、18～64歲100元、65歲以上40元。只編輯學生測試，不改subject。正常與邊界應驗證，正確版通過且九個故障版被抓到。

## 作答與操作

編輯 `exercises/code/11-1.rs`；需要保留題目明訂的函式名稱、參數與回傳型別。實作方式可自行選擇，沒有要求的額外限制不要自行加入。

```sh
cargo run -- lesson 11-1
cargo run -- manual 11-1
cargo run -- run 11-1
```

本題自動驗收範圍：測試設計：正確版本必須通過你的測試，九個故障版本必須被你的測試抓到。至少要有一個真正執行的測試；空測試、編譯失敗與逾時都不計通過。

參考答案只由 `cargo run -- answer 11-1` 顯示。先自己設計，再比較；提示是 `cargo run -- hint 11-1`。

## 呼叫範例與預期回傳

### 範例1

呼叫：`ticket(10)`

預期回傳／狀態：50。

### 範例2

呼叫：`ticket(30)`

預期回傳／狀態：100。

上述是函式結果，不是要求印出的文字；請自行推演其他符合規格的情況。

## 完成後的解釋

指出每個測試想排除什麼錯誤；為何空測試或永遠成功的assert不能提供證據？

請另外提出一個未列出的案例，寫下預期與理由。通過有限資料不等於一般性正確證明。
