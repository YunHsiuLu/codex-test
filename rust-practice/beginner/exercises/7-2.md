```sh
cargo run -- lesson 7-2
cargo run -- manual 7-2
cargo run -- run 7-2
```

本題自動驗收範圍：函式契約：外部測試直接呼叫指定函式。main 只供示範，不要求你額外完成畫面輸出；自行測試 main 可用 manual。

參考答案只由 `cargo run -- answer 7-2` 顯示。先自己設計，再比較；提示是 `cargo run -- hint 7-2`。
