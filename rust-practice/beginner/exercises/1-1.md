# 作業 1-1：兩行自我介紹

## 先備與目標

先完成單元 1 的必讀教材，並已完成單元 0 的必要內容。把本單元的模型運用到新的問題，不必模仿教材的變數名稱。

## 規格與資料範圍

依序輸出兩行：`Hello, Rust!` 與 `我正在學程式設計`。標點與空白完全相同。不要加額外提示。此題沒有可變輸入，十項是輸出性質，不冒充十筆不同輸入。

## 作答與操作

編輯 `examples/unit01_01.rs`；需要保留題目明訂的函式名稱、參數與回傳型別。實作方式可自行選擇，沒有要求的額外限制不要自行加入。

```sh
cargo run -- lesson 1-1
cargo run -- manual 1-1
cargo run -- run 1-1
```

本題自動驗收範圍：完整程式：自動餵入 stdin，檢查 stdout、stderr 與退出碼。

參考答案只由 `cargo run -- answer 1-1` 顯示。先自己設計，再比較；提示是 `cargo run -- hint 1-1`。
