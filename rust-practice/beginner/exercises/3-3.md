# 作業 3-3：三角形有效性

## 先備與目標

先完成單元 3 的必讀教材，並已完成單元 2 的必要內容。把本單元的模型運用到新的問題，不必模仿教材的變數名稱。

第二～四單元的 `support::read_i64`／`read_f64` 是本課提供、已完成的輸入工具，不是 Rust 內建。每次呼叫讀一行；本題保證輸入符合下列契約。暫時保留 `use` 與讀取呼叫，第六單元會拆解標準輸入。

## 規格與資料範圍

分三行輸入三個整數邊長，每個介於 -1000000～1000000。三邊都正且任兩邊和嚴格大於第三邊才輸出 valid，否則 invalid。本題不分類等腰或直角。

## 作答與操作

編輯 `examples/unit03_03.rs`；需要保留題目明訂的函式名稱、參數與回傳型別。實作方式可自行選擇，沒有要求的額外限制不要自行加入。

```sh
cargo run -- lesson 3-3
cargo run -- manual 3-3
cargo run -- run 3-3
```

本題自動驗收範圍：完整程式：自動餵入 stdin，檢查 stdout、stderr 與退出碼。

參考答案只由 `cargo run -- answer 3-3` 顯示。先自己設計，再比較；提示是 `cargo run -- hint 3-3`。
