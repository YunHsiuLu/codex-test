# 作業 4-1：範圍累加與空範圍

## 先備與目標

先完成單元 4 的必讀教材，並已完成單元 3 的必要內容。把本單元的模型運用到新的問題，不必模仿教材的變數名稱。

第二～四單元的 `support::read_i64`／`read_f64` 是本課提供、已完成的輸入工具，不是 Rust 內建。每次呼叫讀一行；本題保證輸入符合下列契約。暫時保留 `use` 與讀取呼叫，第六單元會拆解標準輸入。

## 規格與資料範圍

輸入 n，0～1000；以迴圈求 1 到 n 的總和。n=0 時總和為 0，輸出一行整數。自動測試驗結果；使用迴圈的理由與追蹤表另由學習紀錄檢查。

## 作答與操作

編輯 `examples/unit04_01.rs`；需要保留題目明訂的函式名稱、參數與回傳型別。實作方式可自行選擇，沒有要求的額外限制不要自行加入。

```sh
cargo run -- lesson 4-1
cargo run -- manual 4-1
cargo run -- run 4-1
```

本題自動驗收範圍：完整程式：自動餵入 stdin，檢查 stdout、stderr 與退出碼。

參考答案只由 `cargo run -- answer 4-1` 顯示。先自己設計，再比較；提示是 `cargo run -- hint 4-1`。

## 呼叫範例與預期輸出

### 範例1

stdin（每行資料後按Enter）：

```text
5
```

stdout：

```text
15
```

### 範例2

stdin（每行資料後按Enter）：

```text
10
```

stdout：

```text
55
```

## 完成後的解釋

以 n=3 畫出每輪 value 與 total；解釋 n=0 為何不進入迴圈。

請另外提出一個未列出的案例，寫下預期與理由。通過有限資料不等於一般性正確證明。
