# 作業 2-1：攝氏換華氏

## 先備與目標

先完成單元 2 的必讀教材，並已完成單元 1 的必要內容。把本單元的模型運用到新的問題，不必模仿教材的變數名稱。

第二～四單元的 `support::read_i64`／`read_f64` 是本課提供、已完成的輸入工具，不是 Rust 內建。每次呼叫讀一行；本題保證輸入符合下列契約。暫時保留 `use` 與讀取呼叫，第六單元會拆解標準輸入。

## 規格與資料範圍

輸入一行有限攝氏小數 C，範圍 -300～1000；輸出 F=C×9÷5+32 的數值，不加單位。數值以絕對 1e-8 加相對 1e-9 容許比較。

## 作答與操作

編輯 `examples/unit02_01.rs`；需要保留題目明訂的函式名稱、參數與回傳型別。實作方式可自行選擇，沒有要求的額外限制不要自行加入。

```sh
cargo run -- lesson 2-1
cargo run -- manual 2-1
cargo run -- run 2-1
```

本題自動驗收範圍：完整程式：自動餵入 stdin，檢查 stdout、stderr 與退出碼。

參考答案只由 `cargo run -- answer 2-1` 顯示。先自己設計，再比較；提示是 `cargo run -- hint 2-1`。
