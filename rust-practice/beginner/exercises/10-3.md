# 作業 10-3：組合解析與錯誤傳遞

## 先備與目標

先完成單元 10 的必讀教材，並已完成單元 9 的必要內容。把本單元的模型運用到新的問題，不必模仿教材的變數名稱。

## 規格與資料範圍

完成 `parse_pair(text:&str)->Result<(f64,f64),String>`。以逗號切開必須恰有兩欄；各trim後解析為有限f64，右欄還必須>0。左欄可負或零。錯誤回Err，文字自由。可用完整match或?，兩種都接受。這不是完整CSV格式，不支援引號或欄位內逗號。

## 作答與操作

編輯 `examples/unit10_03.rs`；需要保留題目明訂的函式名稱、參數與回傳型別。實作方式可自行選擇，沒有要求的額外限制不要自行加入。

```sh
cargo run -- lesson 10-3
cargo run -- manual 10-3
cargo run -- run 10-3
```

本題自動驗收範圍：函式契約：外部測試直接呼叫指定函式。main 只供示範，不要求你額外完成畫面輸出；自行測試 main 可用 manual。

參考答案只由 `cargo run -- answer 10-3` 顯示。先自己設計，再比較；提示是 `cargo run -- hint 10-3`。
