# 作業 9-1：帳戶狀態與修改方法

## 先備與目標

先完成單元 9 的必讀教材，並已完成單元 8 的必要內容。把本單元的模型運用到新的問題，不必模仿教材的變數名稱。

## 規格與資料範圍

完成 Account 與 new、deposit、withdraw。new(balance) 對負餘額 assert panic。存款與提款金額必須>0；提款不可超過餘額；操作失敗回傳false且餘額不變，成功true。初始餘額及每次操作金額絕對值<=1000000000、最多100次，無i64溢位。欄位在本題公開供驗收；實務封裝在教材討論。

## 作答與操作

編輯 `examples/unit09_01.rs`；需要保留題目明訂的函式名稱、參數與回傳型別。實作方式可自行選擇，沒有要求的額外限制不要自行加入。

```sh
cargo run -- lesson 9-1
cargo run -- manual 9-1
cargo run -- run 9-1
```

本題自動驗收範圍：函式契約：外部測試直接呼叫指定函式。main 只供示範，不要求你額外完成畫面輸出；自行測試 main 可用 manual。

參考答案只由 `cargo run -- answer 9-1` 顯示。先自己設計，再比較；提示是 `cargo run -- hint 9-1`。
