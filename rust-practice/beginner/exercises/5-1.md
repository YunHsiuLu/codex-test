## 作答與操作

編輯 `examples/unit05_01.rs`；需要保留題目明訂的函式名稱、參數與回傳型別。實作方式可自行選擇，沒有要求的額外限制不要自行加入。

```sh
cargo run -- lesson 5-1
cargo run -- manual 5-1
cargo run -- run 5-1
```

本題自動驗收範圍：函式契約：外部測試直接呼叫指定函式。main 只供示範，不要求你額外完成畫面輸出；自行測試 main 可用 manual。

參考答案只由 `cargo run -- answer 5-1` 顯示。先自己設計，再比較；提示是 `cargo run -- hint 5-1`。
