# 作業 5-2：把數值限制在範圍內

## 這題要完成什麼？

完成一個函式：把給定的數值限制在指定範圍內。這種操作稱為 clamp。

例如系統只允許０到１００的音量：收到負數就改為０，收到超過１００就改為１００，原本就在範圍內的數值則保留。

**這題要「回傳一個整數給呼叫者」，不要求從鍵盤輸入，也不要求在函式裡印出文字。**

先讀單元５的參數、回傳值與assert說明，再編輯 `examples/unit05_02.rs`。請保留指定介面：

```rust
fn clamp(value: i64, low: i64, high: i64) -> i64
```

這是一行介面說明，不是可以單獨執行的完整程式。實作要寫在作答檔中原函式的大括號內。

## 三個參數與回傳值

| 名稱 | 意義 |
| --- | --- |
| value | 準備被限制的原始數值 |
| low | 允許的最小值，包含這個端點 |
| high | 允許的最大值，包含這個端點 |
| -> i64 | 函式必須把限制後的整數回傳給呼叫者 |

**不能只寫println!印出答案，卻沒有回傳所需的i64。**呼叫者可能要把結果拿去繼續計算，不一定要顯示在終端機。

## 應遵守的四項規則

１．先確認 `low <= high`。若下限大於上限，範圍不合法，必須用assert!觸發panic，不回傳一般數值。

２．若value小於low，回傳low。

３．若value大於high，回傳high。

４．其餘情況回傳原本的value。等於端點也屬於範圍內。

三個參數皆為i64。合法範圍可以包含負數，也可以只有單一數值；**low等於high是合法的**。前置條件只有 `low <= high`，不要自行增加「必須為正數」等限制。

## 呼叫範例與預期回傳

### 範例1

呼叫：`clamp(3, 10, 20)`

預期回傳／狀態：10。

### 範例2

呼叫：`clamp(15, 10, 20)`

預期回傳／狀態：15。

上述是函式結果，不是要求印出的文字；請自行推演其他符合規格的情況。

panic的錯誤訊息文字可自行撰寫，不要求印出字串「panic」。

## 想看畫面輸出時，如何手動試？

原本的main可以留空。若想觀察結果，可以自行把main改成下列呼叫示範，保留你已完成的clamp函式：

```rust
fn main() {
    let a = clamp(3, 10, 20);
    let b = clamp(15, 10, 20);
    println!("{a}");
    println!("{b}");
}
```

這段只示範如何呼叫與顯示，clamp的實作仍由你完成。儲存後執行：

```sh
cargo run -- manual 5-2
```

main只重用上面兩組呼叫，預期stdout為兩行：

```text
10
15
```

若main仍是空的，manual沒有輸出是正常的；**函式有回傳值，不代表程式會自動把它印出來**。main中的這兩次呼叫與println!是手動觀察用，不是額外的評分要求。

## 自動驗收怎麼判斷？

```sh
cargo run -- lesson 5-2
cargo run -- run 5-2
```

驗收器直接呼叫你寫的clamp，檢查每次回傳的整數；另檢查不合法範圍是否觸發panic。共有十項具名案例，含負數、端點與單點範圍，完整資料見 [TEST_CASES.md](../TEST_CASES.md)。

這是函式契約題：main只供示範，不以stdout有沒有印出上述兩行評分。驗收時看到PASS／FAIL，是驗收器的報告，不是clamp本身的輸出。你不需要自己捕捉panic，外部測試會處理預期失敗的情況。

提示：`cargo run -- hint 5-2`。完成後再用 `cargo run -- answer 5-2` 比較參考解法。
