# 作業 12-2：成績彙整與跨情境遷移

## 結業任務

先讀單元12，使用 `projects/gradebook` 的獨立Cargo專案。起始main只保留入口，你自行決定函式與模組；請完成同資料夾的DESIGN.md。這次應從需求設計，不能只補教材的公式。

## 完整契約

每個非空白行是 `name,score`，恰兩欄。姓名trim後非空，不能含逗號；分數必須有限且在0～100，可含小數。以trim後姓名完整相同分組，大小寫區分，求各組平均。以Rust字串字典序排序，輸出表頭 `name,average`，後面每人一行 `姓名,平均`，平均固定兩位小數。

共同規則：不帶程式參數時讀stdin；恰一參數時視為UTF-8文字檔路徑；兩個以上參數 stderr `usage: gradebook [path]` 並exit 2。讀取stdin或檔案失敗（含無效UTF-8）stderr `error: cannot read` 並exit 1。空白行略過，但錯誤行號按原始文字從1起算。格式、解析或領域失敗 stderr `error: line N` 並exit 1；多個錯誤回報遇到的第一行。無有效資料 stderr `error: no data`、exit 1。錯誤時stdout必須為空，成功時stderr必須為空、exit 0。先完整驗證，再輸出，避免半份報表。

這是簡單逗號分隔格式，不處理引號、跳脫或欄位中的逗號；不得聲稱為完整CSV解析器。資料量最多1000個非空白行。小數顯示以Rust格式化規則為準，測資避開跨語言捨入的二義案例。

## 呼叫範例與預期輸出

### 範例1

不帶檔案參數，stdin：

```text
Amy,60
Bo,90
Amy,100
```

stdout：

```text
name,average
Amy,80.00
Bo,90.00
```

stderr為空，退出碼0。

### 範例2

不帶檔案參數，stdin：

```text
Amy,101
```

stdout為空，stderr：

```text
error: line 1
```

退出碼1。輸入完兩組範例所列資料後，均需送出EOF。

## 操作

```sh
cargo run -- lesson 12-2
cargo run -- manual 12-2
cargo run -- manual 12-2 data/grades.csv
cargo run -- run 12-2
```

或在beginner中直接 `cargo run --manifest-path projects/gradebook/Cargo.toml`。檔案參數放在原生Cargo獨立的 `--` 後。

## 自動與人工評量

自動驗收至少十組獨立stdin或參數案例，檢查stdout、stderr與退出碼，包含空資料、錯誤、CRLF、檔案與邊界；清單見 [TEST_CASES.md](../TEST_CASES.md)。

人工評量另檢查：是否清楚分離I/O與計算、模組是否合理、能否說明所有權、是否自行新增有效測試，以及DESIGN.md是否提供可重現證據。通過程式測試不直接算設計說明完成。建議兩專案各自評分，避免只在同一個物理情境內重做。

參考答案使用 `cargo run -- answer 12-2`；先完成自己的拆解與測試，再閱讀多檔案答案。
