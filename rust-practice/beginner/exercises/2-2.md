# 作業 2-2：秒數拆成時分秒

## 先備與目標

先完成單元 2 的必讀教材，並已完成單元 1 的必要內容。把本單元的模型運用到新的問題，不必模仿教材的變數名稱。

第二～四單元的 `support::read_i64`／`read_f64` 是本課提供、已完成的輸入工具，不是 Rust 內建。每次呼叫讀一行；本題保證輸入符合下列契約。暫時保留 `use` 與讀取呼叫，第六單元會拆解標準輸入。

## 規格與資料範圍

輸入一行整數 total，範圍 0～100000；輸出 `小時 分鐘 秒`，以一個空白分隔。小時可超過 23；分鐘與秒必須在 0～59。

## 作答與操作

編輯 `examples/unit02_02.rs`；需要保留題目明訂的函式名稱、參數與回傳型別。實作方式可自行選擇，沒有要求的額外限制不要自行加入。

```sh
cargo run -- lesson 2-2
cargo run -- manual 2-2
cargo run -- run 2-2
```

本題自動驗收範圍：完整程式：自動餵入 stdin，檢查 stdout、stderr 與退出碼。

參考答案只由 `cargo run -- answer 2-2` 顯示。先自己設計，再比較；提示是 `cargo run -- hint 2-2`。

## 例子

輸入 `3661`，輸出 `1 1 1`。

## 完成後的解釋

為何分鐘不能直接寫 total / 60？用 3661 手算。
