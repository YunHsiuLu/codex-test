## 呼叫範例與預期回傳

### 範例1

呼叫：`let mut values = vec![1, 2, 1, 3]; remove_value(&mut values, 1)`

預期回傳／狀態：回傳 2；values 變為 [2, 3]。

### 範例2

呼叫：`let mut values = vec![1, 2, 3]; remove_value(&mut values, 9)`

預期回傳／狀態：回傳 0；values 仍為 [1, 2, 3]。

上述是函式結果，不是要求印出的文字；請自行推演其他符合規格的情況。
