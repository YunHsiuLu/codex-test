# 參考設計：運動資料

input 只決定文字來源；parse 將外部文字驗證成 Record；analysis 接收已驗證的借用切片；main 最後才決定格式與退出碼。這是內部模組約定，公開成函式庫時應封裝 Record 或在分析入口重新驗證。

先解析全部資料，再檢查累加的有限性，才能遵守規格的錯誤優先順序；任何失敗之前都沒有印出半份報表。記憶體 O(n)，解析與加總各走一次 O(n)。若資料超過本題規模，可重新設計串流模型與錯誤優先順序。

平均速度是總位移／總時間。有限性不能證明數值沒有捨入或消去誤差；目前模型不是完整數值分析或量測不確定度分析。

具名案例見 TEST_CASES。學生仍應自行提出不同案例並說明理由，不能用這份參考設計取代自己的報告。
