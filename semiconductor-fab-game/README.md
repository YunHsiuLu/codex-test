# 晶圓帝國：半導體產線模擬器

本機端 2D 半導體產線經營遊戲。玩家從矽晶圓供應開始，購買、配置並接線製程設備，完成訂單以取得資金，再研發與擴充更高階的產線。

本專案只在本機執行；不需要上傳 Git，也不需要帳號登入。

## 系統需求

- Node.js 22.13.0 或更新版本
- npm（隨 Node.js 一起安裝）
- Chrome、Safari 或其他現代瀏覽器

可在終端機確認版本：

```bash
node --version
npm --version
```

若尚未安裝 Node.js，請從 [Node.js 官方網站](https://nodejs.org/) 安裝目前的 LTS 版本後，再重新開啟終端機。

## 第一次安裝

1. 開啟「終端機」。
2. 進入遊戲資料夾：

   ```bash
   cd "/Users/lvyunxiu/codex test/semiconductor-fab-game"
   ```

3. 安裝所需套件：

   ```bash
   npm install
   ```

安裝只需要在第一次執行，或專案套件有更新時進行。

## 啟動遊戲

在遊戲資料夾內執行：

```bash
./start.sh
```

腳本會在背景啟動遊戲並顯示網址，之後使用瀏覽器開啟：

```text
http://localhost:3000/
```

啟動前請先完成上方的 `npm install`。`node_modules` 是每台電腦自行安裝的可重建套件，不屬於遊戲原始碼，也不需要隨專案分享。啟動後可關閉終端機，遊戲仍會持續執行。

若無法開啟，請查看遊戲資料夾中的 `.game-server.log` 記錄檔。

仍可使用 `npm run dev` 以前景模式啟動，適合開發時查看即時記錄。

## 開始遊玩

1. 從「設備採購」購買濕式清洗槽。
2. 在訂單市場選擇一筆基礎清洗訂單，工作區會出現對應的 OUTPUT。
3. 將設備放進工作區，並用 OUT → IN 建立 `SOURCE → 清洗槽 → OUTPUT` 接線。
4. 接線完成後，SOURCE 會依自身等級自動投入矽晶圓；多個 OUT 會將 LOTS 平均分配給可運轉的訂單。點擊 SOURCE 也能立即補料。
5. 完成指定 LOTS 後，訂單依良率付款。賺得資金後可研發設備等級上限，並選購新、舊等級的設備。

可同時承接多筆訂單；每筆訂單都會在工作區產生專屬 OUTPUT。若要取消，請在該 OUTPUT 點選「違約」並支付違約金。SOURCE 為獨立十階系統：全部 SOURCE 達 MAX 後，才能購入下一台 SOURCE。

## 停止遊戲

在遊戲資料夾內執行：

```bash
./stop.sh
```

下次要玩時，只要再次進入資料夾並執行 `./start.sh`，不必重複 `npm install`；只有在剛取得原始碼、刪除套件或套件清單更新時才需要重新安裝。

## 驗證與測試

在遊戲資料夾內可執行：

```bash
npm test
npm run lint
```

- `npm test`：建立遊戲並執行核心產線、訂單與畫面測試。
- `npm run lint`：檢查程式撰寫規則。

## 常見問題

### 瀏覽器無法開啟網站

重新執行 `./start.sh`，並重新整理 `http://localhost:3000/`。若仍無法開啟，請查看 `.game-server.log`。

### 顯示找不到 `npm` 或 Node.js 版本太舊

請安裝或更新 Node.js LTS，重新開啟終端機後再執行安裝與啟動步驟。

### 關掉終端機後遊戲無法使用

本版本使用背景本機伺服器；關閉終端機不會停止遊戲。需要停止時，請執行 `./stop.sh`。
