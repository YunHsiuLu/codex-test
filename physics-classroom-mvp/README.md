## 老師密碼與安全

介面只要求老師密碼。後台使用 Firebase Authentication 的 email/password，固定老師帳號由 Firebase Console 建立；不是把密碼藏在 JavaScript 裡。原本不加 Authentication 的 MVP 限制，已依使用者要求修正為真正的資料庫寫入權限。

規則只接受指定老師 UID 與 password 登入提供者。未登入、其他帳號、自行註冊或猜到老師網址，都不能新增、修改、刪除向量或模型，也無法自行取得老師權限。學生可讀取已知教室代碼的資料，不能列舉所有教室。

老師密碼由本人在 Firebase Console 設定；本程式未記錄密碼。登入使用分頁工作階段持續性，並提供「鎖定老師端」。關閉分頁或在共用設備上結束授課時，建議按鎖定。已分享出去的老師密碼具有同一老師權限。

修改密碼：由老師本人在 Firebase Console 的 Authentication 管理該帳號。不要刪除重建帳號，否則 UID 會變，需要同步更新 `scripts/build-rules.mjs` 的授權 UID、測試 fixture，再產生及部署規則。Firebase 管理員權限另由 Firebase Console 管理，與本網站老師密碼不同。

## 模式一：自由向量

新增／選取向量，設定名稱、色彩、起點與分量，再按「儲存並同步」。移動起點會平移向量；終點＝起點＋分量。每室５０個槽位、座標與分量 −１００～１００。

## 模式二：向量運算

先在自由向量模式新增所需向量，再切到向量運算，選取 A、B：

- A＋B：顯示首尾相接與合向量。
- A−B：顯示 A＋（−B）。
- A×B：顯示右手定則方向與叉積分量。

以兩向量的分量運算並移至共同原點；不使用原本起點決定結果。修改 A／B 後會重新計算。結果與公式同步到學生。

## 模式三：帶電粒子・電磁場

完整方程：

```text
F = q (E + v × B)
dv/dt = F / m
dr/dt = v
```

參數：電荷 q（C）、正質量 m（kg）、初速度 v₀（m/s）、電場 E（N/C）、磁場 B（T），皆支援三維分量。另可設定總時間、每秒播放的物理時間、顯示倍率。所有物理數值採 SI，顯示倍率只影響畫面，不改變計算結果。

模型假設：均勻且固定的電磁場，非相對論點粒子，初始位置為原點，忽略重力、輻射、碰撞及粒子間作用。以解析解計算任意時間，不以畫面幀數累積數值積分，因此背景分頁恢復後仍能對上教室時間。

支援：

- 螺旋運動、圓周運動、純電場加速、交叉電磁場漂移、電子微秒尺度範例。
- 範例先載入表單，再按「套用參數並歸零」才會全班更新。
- 播放、暫停、歸零、時間滑桿；學生保有自己的視角。
- E、B、v、v×B、電力、磁力、合力的箭頭，各瀏覽器可自行開關。
- 瞬時位置、速度、v×B、qE、q（v×B）、F、速率與動能；純磁場另外顯示迴旋半徑、週期、螺距。
- 淡線為預測軌跡、亮線為已走過軌跡。「看完整場景」只調整目前瀏覽器相機。

不同物理量單位不同，方向箭頭不共用長度比例。實際大小以數值表為準。為維持教學顯示品質，限制最多１００圈，限制顯示軌跡範圍，並拒絕明顯超出非相對論模型的速度。此版本不處理空間變化場、時間變化場或相對論。

## 箭頭與空間參考網格

所有場景向量使用立體箭身、較大的箭頭尖端，以及同色框線／深色底的文字標籤。縮放時標籤保持可讀大小，密集標籤會嘗試避讓。電磁模型標籤附上中文物理量名稱。方向示意箭頭在拉遠時維持可見長度；自由向量與力學速度向量保持其數值長度，只有粗細調整。

網格依完整預測軌跡或向量端點自動擴展，包含 XY 底面與兩個垂直參考面。格距採１、２、５等級並顯示於左下角，故「一個畫面方格」不一定等於一個座標單位。模型的顯示倍率仍代表每公尺對應多少座標單位。網格更新不會重設個人相機；需要重新取景時按「看完整場景」。


## 斜拋速度分解（２０２６－１０－０２）

切到「拋體運動」後，預設同時顯示綠色合速度、橘色水平分量 vₓ、藍色垂直分量 v_z。三支箭頭都由粒子位置出發，長度採同一比例尺；虛線補出分量相加的平行四邊形。由於專案採 Z 軸向上，垂直分量使用 v_z，並非 v_y。

- 水平 vₓ＝v₀ cosθ：忽略阻力時固定。
- 垂直 v_z＝v₀ sinθ−gt：上升為正、最高點為零、下降為負。
- 最高點零分量不畫假箭頭，數值仍顯示０；合速度與水平分量在此刻重合。
- 右側「斜拋速度分解」顯示公式、帶正負號的即時分量與合速率。老師可播放或拖動時間滑桿觀察。
- 箭頭選項可分別開關三種速度；開關只影響當前瀏覽器，學生也可自行比較，不改變教室物理數據或其他人的視角。

此次只更新前端，部署可在 Terminal 執行 `npm run firebase -- deploy --only hosting`（使用專案 Firebase CLI 包裝腳本與既有登入設定）。


## 多物體拋體比較（２０２６－１０－０２）

老師選擇「多物體拋體比較」→選教學範例→「載入範例到表單」→「套用比較並歸零」。按「2D Front (XZ)」框住所有軌跡，再播放或拖動共同時間滑桿。載入範例只填表，套用才同步。

| 教學範例 | 可討論的問題 |
| --- | --- |
| 同初速，不同仰角 | 同高度起落時，４５度射程最大；高度與飛行時間如何變化？ |
| 互餘角 | ３０度與６０度同初速、同射程，為何落地時間不同？ |
| 射程皆３０公尺 | 不同仰角要多大初速？４５度需要的初速最小。 |
| 同水平初速度 | 同一時刻水平位置相同，垂直運動不同。 |
| 同鉛直初速度 | 同高度起落時，最高點與飛行時間相同，射程不同。 |
| 自由落下與水平拋射 | 同高度、同時釋放，是否同時落地？ |

可設定２至４個物體，各有名稱、初速、仰角、起點高度、水平起點、延後發射時間；共用重力、播放倍率與顯示倍率。這些範例是初始條件，手動改值後不會持續鎖定同射程或同速度。

每個物體使用自身顏色與瞬時合速度箭頭；「觀察物體」決定額外顯示誰的水平／垂直速度。數值表可切換「同一時刻的位置與速度」及「完整飛行預測」。射程是相對起點的水平位移；落點 X 是共同座標。飛行時間不含等待，落地時刻含延後發射。每個物體落地後停止、速度顯示０，其他物體繼續。

學生只讀物理參數與共同時鐘；相機、觀察物體、表格欄位、箭頭與預測軌跡開關皆為各人本機選擇。老師關閉預測軌跡不會強制學生關閉，並非測驗保密模式。模型限 XZ 平面、均勻重力、無阻力、無碰撞／反彈。

場景庫與 JSON 匯出包含多物體設定，舊版 JSON 仍可載入。「看完整場景」現在保留所選的平面觀看方向；２０２６－１０－０６起，２Ｄ改為正交相機。新增 `src/comparison.js` 負責物理、`src/comparison-ui.js` 負責比較介面。此次新增資料庫欄位及規則，必須以 `npm run deploy` 同時發布 Hosting 與 database。

## 演示時的標籤（２０２６－１０－０６）

## 真正２Ｄ平面（２０２６－１０－０６）

XY／XZ／YZ 使用正交投影，只顯示所選平面的網格及兩軸；切換時原點位於畫布中央。拖曳可平移、滾輪／雙指可縮放，無法旋轉。「重設視角」與「看完整場景」保留所選平面、原點置中；按「3D 視角」才回到空間透視。２Ｄ是三維運動在該平面的投影，垂直於該平面的位移不會展開。
