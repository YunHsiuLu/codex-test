# Together 專案交接

更新日期：２０２６年９月２７日

## 任務與目前成果

使用者要求製作模仿 Teams 的聊天軟體。本次在 `teams-chat` 新建獨立、可啟動的聊天 MVP，使用繁體中文介面及 Teams 風格配色與側欄。此資料夾屬於上層 `codex test` Git 儲存庫，本次未提交或推送。

已完成公開頻道、即時聊天、成員在線狀態、搜尋、未讀、引用回覆、按讚、編輯／刪除自己的訊息、附件上傳下載、共用檔案清單、手機版介面及本機資料保存。所有介面功能使用實際後端；初始訊息與成員有明確「示範」標示。

## 檔案結構

- `server.js`：Node.js 原生 HTTP API、SSE、Cookie 工作階段與序列化原子檔案寫入。
- `public/index.html`：主要頁面與表單。
- `public/style.css`：桌面、窄螢幕與手機響應式介面。
- `public/app.js`：前端狀態、渲染、操作與同步。
- `test/server.test.js`：獨立資料目錄及隨機連接埠的整合測試。
- `docs/分享範例.txt`：實際附件驗收用檔案。
- `docs/desktop-preview.png`：瀏覽器驗收畫面。
- `data/workspace.json`：執行時資料，已忽略，不應推送。

## 不同電腦的設定與啟動

１．先閱讀本文件及 README，確認新電腦有 Node.js 22 以上。
２．複製本專案資料夾；如要保留聊天記錄，停止舊伺服器後，另外安全複製 `data`。Git 不會攜帶這個資料夾。
３．於專案內執行 `npm test`，再執行 `npm start`。不需要 `npm install`。
４．瀏覽器開啟 `http://127.0.0.1:4310`。
５．Cookie 不會隨檔案搬到新電腦；新瀏覽器會建立新身分，舊訊息仍存在，但無法以新身分編輯舊身分的訊息。目前沒有帳號復原或身分遷移介面。

預設只對本機開放。`PORT` 可指定其他連接埠，`DATA_DIR` 可指定資料目錄；相對的 DATA_DIR 依啟動時所在目錄解析。若需區網測試，README 有 HOST 設定說明，需先評估下列限制。

本次完成時曾啟動本機 4310 服務；此為當次開發程序，不能假設切換電腦或關閉應用程式後仍持續執行。可用 `lsof -nP -iTCP:4310 -sTCP:LISTEN` 確認。

## 驗證證據

- `npm test`：九個功能子測試，加上外層流程共十個測試，全部通過。
- API 實測獨立使用者、即時 SSE 廣播、附件位元內容、重啟後還原、編輯／刪除擁有者檢查，以及惡意來源與無效輸入拒絕。
- Codex 內建瀏覽器實際填寫名稱、按 Enter 發話、搜尋、按讚、引用回覆、建立「功能驗收」頻道、選取並傳送中文檔名附件，確認共用檔案清單。
- 使用 `127.0.0.1` 與 `localhost` 分離瀏覽器身分，驗證雙向訊息與編輯結果自動同步；不靠重新整理。
- 檢視桌面版與手機版。手機實測 DOM 視窗寬度 390、文件寬度 390，沒有橫向溢出，頻道抽屜可切換。
- 瀏覽器錯誤紀錄在驗收當時為空。
- 附件下載內容及刪除後不可下載，已由整合測試驗證；瀏覽器端實測完成選檔、發送及列表顯示。

本機資料保留「體驗者」「協作夥伴」及功能驗收訊息供操作參考，另有一次 API 連線檢查建立的「API驗收」身分；這些皆為本次測試資料。整合測試的 Alice／Bob 資料使用隔離目錄並自動清理。

## 明確限制與後續方向

- 這不是 Microsoft Teams 客戶端，也沒有接入 Microsoft 服務。
- 目前僅以顯示名稱加入。Cookie 提供同瀏覽器操作歸屬，沒有密碼驗證、註冊或真正的身分驗證，不能以名稱認定身分。
- 所有頻道公開，無私訊、權限控制、正式管理員與帳號恢復。
- 沒有音視訊通話、通知推播與雲端部署；不要把本機 MVP 直接暴露到網際網路。
- JSON 全量資料、附件 Base64 與全量訊息重新抓取適合小型本機體驗，下一階段應改為資料庫、附件獨立儲存、訊息分頁與增量推送。
- 每則訊息 5000 字、每份附件 5 MB。重新整理不保留未送出的草稿，切換頻道只保留文字草稿。
- 同時只能有一個伺服器程序寫入同一份資料。
- 如要正式多人使用，優先補上身分驗證、頻道成員權限、HTTPS、速率限制與備份，再做私訊與通話。

後續請先確認使用者要「本機原型」「校內區網」或「正式雲端服務」，沿用此專案擴充，勿重新建立另一份。

## 區域網路連線說明補充

２０２６年９月２７日查詢：這台 Mac 的 en0 IPv4 為 `192.168.0.128`，目前 4310 仍僅監聽 `127.0.0.1`，尚未切換成區網模式。IP 可能隨換網路或 DHCP 配發而改變，後續請重新查詢 `ipconfig getifaddr en0`。

若要開放同一可信任區網中的其他裝置，先停止既有伺服器，再於專案內執行 `HOST=0.0.0.0 npm start`。其他装置以 `http://192.168.0.128:4310` 連線；不可使用 localhost 或 127.0.0.1，因為那會指向各自裝置。主機需持續運作且不要休眠。若無法連線，確認防火牆允許 Node.js 的傳入連線，以及 Wi-Fi／校園網路未啟用用戶端隔離或跨 VLAN 封鎖。無需設定路由器對外連接埠轉送。

此輪僅確認本機設定並提供步驟，沒有調整監聽範圍、防火牆、路由器設定，也沒有跨實體裝置驗收。現有版本無密碼驗證，僅適合可信任區網內體驗。
