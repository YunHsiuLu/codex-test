# Together

繁體中文、Teams 風格的區網聊天軟體。使用 Node.js 22 以上及原生 JavaScript，無第三方套件，不需要 npm install。

## 開啟與關閉

在本專案資料夾執行：

```sh
./start.sh
./stop.sh
```

也可以從任意資料夾執行腳本的完整路徑。`start.sh` 會在背景啟動，顯示本機與目前的區網網址。終端機關閉後服務繼續運作；主機仍須保持開機、不休眠。`stop.sh` 會核對 PID、程序啟動時間與命令後才停止，不會任意終止占用連接埠的程式。

- 預設監聽 `0.0.0.0:4310`，同一可互通區網的電腦與手機可連線。
- 本機使用 `http://127.0.0.1:4310`，其他裝置使用啟動腳本顯示的主機區網網址。
- 重複執行 `start.sh` 只顯示目前服務；重複執行 `stop.sh` 也安全。
- 紀錄與 PID 在 `.run/`，已忽略。啟動時保留一份上次的紀錄 `server.log.previous`。
- 若連接埠已由手動啟動的服務占用，腳本會報錯並保留該程序，先停止原服務再重試。
- 本機開發也可使用 `npm start`，這會在前景執行且預設只監聽本機；此方式不由 stop.sh 管理。

指定連接埠或只允許本機時，請先停止再啟動：

```sh
PORT=4312 ./start.sh
HOST=127.0.0.1 ./start.sh
```

若變更 `RUNTIME_DIR`，停止時也要帶相同的 `RUNTIME_DIR`。程式僅支援同一資料目錄由一個伺服器程序使用。請勿開啟路由器的對外連接埠轉送。

## 第一次使用與帳號審核

１．主機開啟 `http://127.0.0.1:4310`，選擇「建立帳號」。第一個在本機建立的帳號會自動核准並登入，遠端不能搶先取得這個資格。
２．其他成員從區網網址選擇「建立帳號」，填寫顯示名稱、帳號及密碼，送出後等待審核。
３．本機管理者登入後，右上角「帳號審核」會即時顯示待審數量。點選後可逐一「核准」或「拒絕」。誤拒者仍可在清單重新核准。
４．通知申請者使用原帳號密碼登入。不需要管理者代設或接觸對方的密碼。

帳號使用 3～32 個英文字母、數字或 `_ . -`，不分大小寫；密碼為 10～128 個字元。所有已核准成員的聊天功能相同，皆可聊天、建立頻道與分享附件，只能編輯／刪除自己的訊息。

審核功能依「主機本機連線＋已核准帳號登入」開放，沒有另外設定管理員角色。因此任何已核准成員若實際使用主機的本機入口登入，都可審核。請保護主機的實體與作業系統存取。本機審核請使用 `127.0.0.1` 或 `localhost`；使用主機的區網 IP 會視為區網連線。此版本不能直接置於同機反向代理後方，否則遠端連線可能被代理變成本機來源；代理部署需先重新設計本機管理入口隔離。

登出會撤銷目前工作階段，登入有效期為七天。密碼使用隨機鹽值與 scrypt 雜湊保存，資料檔保存的是登入權杖雜湊。目前未提供忘記密碼、自助重設密碼或停用既有帳號的介面。

## 新訊息分頁提示

當其他成員的新訊息尚未讀取時，分頁標題會顯示 `（N）新訊息｜Together`，圖示加上紅點。切回對應頻道閱讀後，數量會減少或恢復原標題。不同帳號的已讀記錄分開保存在瀏覽器，首次登入不把舊歷史訊息全部當成新通知。

- 自己發的訊息、示範訊息、按讚或編輯不會新增未讀數。
- 查看共用檔案或搜尋結果時，不會將整個頻道自動標記已讀。
- 不要求瀏覽器通知權限，也不會發送系統推播；網頁關閉、裝置休眠或離線時無法即時更新。

## 附件與原始碼

所有已核准成員皆可上傳、查看與下載附件，單檔最大 5 MB。附件以資料形式保存，不會按上傳檔名覆寫原始碼。

遠端沒有修改原始碼、讀取伺服器資料檔、執行命令或變更伺服器設定的 API。HTTP 只提供明列的前端資源；`server.js`、`auth.js`、`data/` 和啟停腳本不公開。瀏覽器正常運作需要下載 HTML、CSS、前端 JavaScript，這些前端內容本來就能查看；修改自己瀏覽器的畫面不會修改主機檔案。

## 舊資料與搬機

升級後仍保留舊訊息、附件與顯示名稱。首次啟動新版會備份到 `data/workspace-before-login.json`，撤銷舊版沒有密碼的登入權杖。舊名稱不會自動變成可登入的帳號，請另建帳號；新的帳號不會取得舊身分訊息的編輯權。

停止伺服器後，安全複製整個 `data/` 到新主機。正式帳號可用原帳密重新登入，新電腦需安裝 Node.js 22 以上。不要複製 `.run/` 的程序記錄。`data/` 含私人訊息、附件、密碼雜湊與工作階段資料，已由 Git 忽略，勿公開上傳。

## 驗證與使用範圍

```sh
npm test
```

測試使用專案內的獨立暫存資料與連接埠，不修改正式聊天資料。涵蓋登入、待審阻擋、本機核准與拒絕、遠端防越權、附件、即時同步、持久化、通知計數，以及腳本重複操作、PID 身分核對與連接埠占用。

目前使用 HTTP，登入密碼與訊息沒有傳輸加密，只適用可信任區網。跨網路或正式公開部署應先加入 HTTPS 及獨立本機管理入口。JSON 全量儲存與附件 Base64 適合小型團隊體驗，沒有訊息分頁、私訊、通話、Microsoft Teams 整合或資料庫叢集。

完整交接與實測記錄請見 [HANDOFF.md](HANDOFF.md)。
