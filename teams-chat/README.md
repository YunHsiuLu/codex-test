# Together

受 Microsoft Teams 介面啟發的繁體中文本機聊天軟體。採用原生 JavaScript 與 Node.js，無第三方套件、無建置步驟，也不需要 API 金鑰。

## 啟動

需要 Node.js 22 或更新版本。於專案資料夾執行：

```sh
npm start
```

開啟 http://127.0.0.1:4310，輸入顯示名稱即可開始。停止時，在執行伺服器的終端機按 Ctrl+C。

如果連接埠已被使用，可改用：

```sh
PORT=4312 npm start
```

預設只監聽本機。需要可信任區網內的其他電腦連線時，可在充分理解以下限制後使用 `HOST=0.0.0.0 npm start`，其他裝置使用主機的區網 IP 與連接埠。這不是公開網路部署方案。

## 已實作

- Teams 風格的紫色導覽、頻道清單、聊天室與成員資訊面板。
- 繁體中文介面與手機版頻道抽屜。
- 顯示名稱與瀏覽器工作階段，可修改名稱。
- 多身分即時訊息同步、在線狀態、自動重連。
- 建立公開頻道、頻道未讀提示、目前頻道的訊息搜尋。
- Enter 傳送、Shift+Enter 換行，支援中文輸入法組字。
- 引用回覆、按讚／切換既有表情反應、表情插入。
- 編輯與刪除自己發送的訊息。
- 每個訊息最多一份 5 MB 附件，支援下載與共用檔案清單。
- 伺服器端保存資料，重啟後仍保留訊息、附件、頻道與身分。

初始的三位成員與三則訊息均為標記過的示範資料，不會自動回覆。

## 測試多人協作

使用兩個不同瀏覽器或一個一般視窗加上一個無痕視窗，分別輸入不同名稱。也可以在同一台電腦分別使用 `http://127.0.0.1:4310` 與 `http://localhost:4310`，兩個來源具有不同的 Cookie 與本機偏好，但連到同一個伺服器。

一般瀏覽器的同來源分頁共用身分，並不會變成兩個人。

## 資料與限制

資料在 `data/workspace.json`，已由 `.gitignore` 排除。附件以 Base64 保存在同一檔案，備份時請先停止伺服器，再複製整個 `data` 資料夾。不要將此資料檔上傳 Git；它包含訊息、附件與工作階段權杖。

這是可操作的本機協作 MVP，尚無密碼登入、身分驗證、私訊、頻道權限、管理員功能、音視訊通話、Microsoft Teams 整合或雲端部署。顯示名稱可以相同，不能證明真實身分。所有頻道、訊息及成員資料都是工作區公開資訊。

資料採單一 Node.js 程序與 JSON 檔案保存；不適合大量訊息、大型附件庫、多人程序同時寫入或正式對外服務。即時通知後會重新抓取完整訊息清單，尚未分頁。草稿只存在目前分頁記憶體；切換頻道會保存文字草稿，但不保留未傳送附件，重新整理會清除草稿。刪除訊息沒有復原功能。

## 驗證

```sh
npm test
```

測試會在專案內建立獨立暫存資料，啟動隨機連接埠的測試伺服器，並在結束時清理。不會讀寫使用中的 `data`。

涵蓋獨立身分、Cookie 恢復、頻道建立、跨用戶 SSE、附件內容、回覆、反應切換、編輯／刪除的擁有者檢查、跨來源與無效輸入、附件大小限制，以及重啟後資料保留。

詳見 [HANDOFF.md](HANDOFF.md) 的目前驗收記錄與後續工作。
