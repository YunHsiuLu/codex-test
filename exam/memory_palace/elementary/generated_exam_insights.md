# Generated Exam Insights：高一物理

## 小考_前半冊模擬考

- 範圍：Ch1 科學態度、物理量與單位、數量級；Ch2 原子結構、原子尺度與基本交互作用；Ch3 運動描述、牛頓定律與天體運動。
- 前半冊模擬考適合把「單位與數量級」作為閱讀原子尺度、力學量與萬有引力題的共同工具，而不是只在 Ch1 單獨考記憶。
- Ch2 到 Ch3 的自然橋接是「基本交互作用作為力的來源」：重力連到天體與近地表重力，電磁力連到日常接觸力，強作用連到原子核穩定。
- Ch3 題目應同時檢查語意辨識與運算：位移與路徑長、平均速度與平均速率、速度變化與加速度、合力與單一力不可混淆。
- 前半冊 A／B 卷可維持同配分與同題型比例，但用不同情境交換重點：A 卷偏跨章概念串接，B 卷偏基本定義與力學運算穩固。

## 小考_前半冊模擬考：較難版

- 較難版不宜只增加計算量；更有效的難度提升是讓學生同時處理「概念判斷＋數量關係＋範圍邊界」。
- Ch1 可用量綱分析、控制變因、單位前綴換算提高鑑別度。
- Ch2 可用原子序、質量數、同位素、原子與原子核尺度比例，以及基本交互作用的作用距離與迷思判斷來增加深度。
- Ch3 較難題適合加入速度變號後的路徑長判斷、萬有引力比例變化、克卜勒定律與牛頓萬有引力的解釋關係。
- 難題仍應維持高一範圍：可以要求多步推理，但不要偷渡選修物理的進階推導。

## 小考_Ch1至Ch5模擬考

- A／B 卷定位為中等複習卷，題目應覆蓋 Ch1 到 Ch5 的核心概念，但避免把同一題做成過長的跨章推理。
- C 卷定位為較難進階卷，適合給願意挑戰的學生；難度可來自多步比例、速度變號、功能定理、電磁感應與能量守恆的整合。
- Ch4 與 Ch5 的自然整合點是電磁感應與發電：磁通量改變產生感應電流，但輸出的電能必須來自外界做功或其他能量轉換。
- Ch5 能量題要持續提醒學生：有摩擦時機械能可能不守恆，但總能量守恆仍成立；能源危機不是總能量消失，而是可用能量品質與效率問題。
- Ch1 到 Ch5 模擬考若不使用圖片，可多用文字情境描述右手定則、冷次定律、波速關係與功能定理；若使用圖片，需另列圖片需求。

## 章節小考 C 卷

- C 卷保持小考固定配分與學測型複選制度，但難度應來自比例推理、跨概念辨析、反例判斷與多步計算，而非超出高一範圍的選修推導。
- Ch1--Ch2 適合把單位量綱、量級、原子序／質量數、模型證據與尺度限制串成同一推理鏈；Ch2--Ch3 適合從基本交互作用連到重力與日常接觸力的微觀來源。
- Ch3 較難題應明確處理折返：位移可相消，路徑長必須分段取量值；牛頓定律題需區分「速度方向」與「加速度／合力方向」。
- Ch4 較難題以右手定則、冷次定律、磁通量改變與能量守恆為核心。若題目需要圖，可改成學生在混合題自行繪製受力圖、線圈電流與磁場方向，不必依賴外部圖片。
- Ch5--Ch6 較難題以能量轉換與守恆作為共同語言：摩擦使機械能轉成內能；核反應的質量虧損、光電效應與能階躍遷皆要回到能量守恆與量子化。
- 對較長的複選題，應在題目檔中於複選題區前主動換頁，避免共用防換頁題塊在頁尾造成題幹或選項截斷。
