# Teacher Feedback Log：高一物理

本檔用來記錄使用者審閱、修正考卷後形成的可重用出題原則。

## 使用方式

- 每次使用者修改高一考卷後，先讀取修正後的 `main.tex`、答案表、圖片需求與相關素材。
- 若能取得修正前版本，需比較差異；若無修正前版本，則直接從修正後內容整理偏好。
- 記錄重點應放在可重用規則，而不是完整複製題目。
- 若修正涉及章節專屬概念，補到對應 Ch 資料夾或 global chunk；若是通用命題習慣，補到本檔或 `global/question_design_matrix.md`。

## 待累積項目

- 概念精準度修正。
- 難度與配分調整。
- 單選、複選、混合題的題型偏好。
- 常見迷思選項的設計方式。
- 圖片題的使用邊界與圖像標示習慣。
- LaTeX 排版與文字敘述風格。

## 已確認偏好

- 若複選題使用 `\mchoices` 並顯示「應選 x 項」，答案數只能設計為 2 項或 3 項。避免應選 1、4、5 項，因為 1 項應改為單選，4 或 5 項則會讓提示降低鑑別度並使題目不夠漂亮。
