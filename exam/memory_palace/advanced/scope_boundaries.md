# Advanced Scope Boundaries

選修物理記憶宮殿依年級與冊別分層，出卷時先判斷年級，再判斷冊別與章節。

## 年級對應

- 高二範圍：選修物理 I、選修物理 II。
- 高三範圍：選修物理 III、選修物理 IV、選修物理 V。
- 高一範圍：只使用 `memory_palace/elementary/`，不得使用 advanced 內容。

## 出題規則

- 段考、小考若指定到某冊某章，只使用該冊該章與必要先備知識。
- advanced 的 global chunk 只作跨冊索引，不能取代章節範圍核對。
- 選修物理卷預設為分科型複選題，使用 `\mchoicesblind`。
