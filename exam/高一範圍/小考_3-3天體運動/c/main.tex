\subsection*{混合題參考}由 $T^2\propto a^3$，乙的週期為 $\sqrt{9^3}T=27T$。較靠近中心天體時，等時面積條件使其速率較大。萬有引力提供持續指向中心天體的作用，使速度方向不斷改變，形成彎曲軌道。
