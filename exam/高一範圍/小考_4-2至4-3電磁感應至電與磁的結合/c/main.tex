\subsection*{混合題參考}靠近時穿過線圈、方向由 N 極指向線圈的磁通量增加。線圈須以靠近端呈 N 極來排斥來近的 N 極，反抗磁通增加。外力克服此反抗所做的功轉為線圈中的電能及可能的熱能，符合能量守恆。
