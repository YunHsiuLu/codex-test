# 英文命題工作流程

１．先讀 `MEMORY_PALACE.md`、`memory_palace/README.md`、`HANDOFF.md`、`memory/TEACHER_FEEDBACK.md` 與本次教材；優先查既有分塊與來源文字，不重複解析整批 PDF。
２．本專案目前採檔案式出題流程：結構化題目、學生卷、教師解析、驗證報告。不要自行擴成網站。
３．區分教過內容的成就測驗與一般能力練習；缺少主課文時不得宣稱符合正式段考教材占比。
４．命題先建立配分與範圍，再寫原創題目。每題必須有答案、評分方式、考點與證據。
５．遵循記憶宮殿的出題檢查；詞彙分級不得當成年級或 CEFR 對照。
６．修改試題以 `exams/g11_midterm_v1.json` 為來源，重新產出相應文件。檢查答案分布、總分及每頁實際渲染。
７．教師版與學生版分開，學生版不得夾帶答案或評分範例。
８．每次任務結束更新 `HANDOFF.md`，寫明完成、驗證、限制、下一步及其他電腦重建方式。未經要求不要 git 上傳。
９．重建前確認老師是否手改輸出 `.tex` 或 Markdown；先保留並比對，把修正整合回主資料和產生器後才可重建，避免覆寫教師改稿。
