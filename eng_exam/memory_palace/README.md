# 英文教材記憶宮殿

沿用物理 exam 專案的「索引 → 概念分塊 → 命題矩陣 → 回查來源 → 教師修正」順序。這是一套檔案式知識庫，新增教材時逐步擴充，不必每次重新解析全部 PDF。

## 出題查詢順序

１．[巡覽入口](../MEMORY_PALACE.md)：範圍、２０個單字、通用命題規則與評分方法。
２．[層級規則](taxonomy.md)：辨別教材事實、自訂練習範圍與尚待確認事項。
３．[概念分塊](g11/chunks/01_unit13_and_transfer.md)：Unit 13 和本卷的可重用教學知識。
４．[命題矩陣](g11/question_design_matrix.md)：能力、題型、題號與證據。
５．[來源對照](source_map.md) 和 `sources/`：只有摘要不夠時才回查文字；版面或文字仍有疑問才讀原文件。
６．[教師回饋](../memory/TEACHER_FEEDBACK.md) 與 [交接](../HANDOFF.md)：優先沿用教師實際修正後版本。

目前只建立高二練習層，不宣稱已涵蓋完整高中英文課程。不同版本課本、年級、學期及課次應各自建索引；共同語言知識可以連結，不要混淆已教範圍。

此次舊物理專案僅唯讀參考其 AGENTS、README、memory_palace 索引及高二卷型。未修改或複製物理題庫。
