# 層級與證據標籤

| 標籤 | 意義 | 本次使用 |
|---|---|---|
| source-confirmed | 可由提供教材確認 | Unit 13 的２０詞、詞彙表級別、校內檢核要求 |
| author-designed | 本次自主設計 | 原創文章、活動表格、作文提示、配分及建議時間 |
| general-language | 可重用語言知識 | 關係子句、時態、連接詞、語境判讀 |
| pending-scope | 尚未取得教學進度 | 主課文、教科書版本、課次文法、雜誌與聽力範圍 |
| teacher-confirmed | 教師明確修正或同意的出題規則 | 目前尚無本英文卷的具體改稿；不得自行加上 |

題目以 `section`、`target`、`difficulty`、`points` 分類；`difficulty` 是命題預估，不是施測結果。Unit 13 直接考點另有 `unit_word` 標籤。

本次３０分直接考查１５個不同目標詞。未直接考的 campus、drip、hint、spin、bore 仍保留在知識庫，後續版本應補足；單字只是出現在句中不算已評量。

大考中心詞彙級別表示詞表分級，不等同高一／高二／高三，也不是 CEFR 對照。第三級詞可作本次教材範圍依據，不能單憑級別宣稱試卷適合所有高二班級。
