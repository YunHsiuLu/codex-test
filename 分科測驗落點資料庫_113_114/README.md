## 後續個案分析需要的資料

請以學生的**單科60級分**提供資料，不要只給總和。例如：

```text
分析年度：115（或欲比較113／114）
分科：數甲__、數乙__、物__、化__、生__、歷__、地__、公__
學測60級分（若有）：國__、英__、數A__、數B__、社__、自__
英聽：A／B／C／F（若校系要求）
想要的校系類型：例如電資、物理、醫藥衛生、商管；是否限定地區／公私立／校名
其他限制：學費、住宿、離家距離、轉系或雙主修等
```

114學年度新增數學乙；113沒有數學乙。因此跨年度比較時，會將兩年度採計規則分開計算，且不把不同採計組合的「加權總分」直接排序。

## 四區判讀規則

每一個校系會先做以下檢查：採計科目是否報考、英聽／學測檢定是否達標、學生依該學年度分則換算的加權分數、113與114最低錄取分數、招生與錄取名額變化，以及各單科的年度百分位。

| 區域 | 初步定義 | 呈現方式 |
| --- | --- | --- |
| 夢幻區 | 推估低於近兩年門檻，且落差明顯；僅保留少數高度偏好的選項。 | 標示主要風險（門檻、名額或科目弱項）。 |
| 挑戰區 | 推估略低於或接近近兩年門檻；有名額增加、分數下修或學生科目優勢等合理理由。 | 顯示與113、114門檻的差距。 |
| 穩健區 | 推估已達或略高於近兩年門檻，且沒有明顯檢定或名額風險。 | 作為志願的主要配置。 |
| 保底區 | 推估高於近兩年門檻且符合所有檢定；仍須保留真正願意就讀的校系。 | 不以「一定錄取」表述。 |

四區是根據歷年資料的風險分層，不是錄取保證。正式填志願時，會再以當年度招生名額、校系分則、成績分布和學生實際成績重算。

## 重要口徑

- 「最低錄取成績」是放榜後，該系組錄取考生中最低的**加權**成績；不是單科級分，也不是未加權總級分。
- 分科與學測用於分發時皆採60級分，但學測60級分不是將15級分直接乘以4。
- 志願序不改變同一校系的分數競爭順序；學生會被分發至第一個符合錄取條件的志願。
